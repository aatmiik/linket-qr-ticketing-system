# Linket — QR-Based Ticket Generation & Verification System

An automated event ticketing system developed using Python to generate personalized QR-enabled tickets and verify ticket authenticity through a web-based verification system.

## Overview

Linket automates the workflow from participant registration data to personalized digital tickets and QR-based verification.

### Workflow

Registration Data  
↓  
Unique Ticket Identification  
↓  
QR Code Generation  
↓  
Personalized Ticket Generation  
↓  
Web-Based Verification  
↓  
Scan Status Tracking

## Key Features

- Automated personalized ticket generation
- Unique ticket identification
- QR-code-based ticket verification
- Web-based validation
- Duplicate scan detection
- Automated ticket image generation
- Scan-status tracking
- Structured ticket management

## Technology Stack

- **Python**
- **Pandas**
- **Flask**
- **Pillow (PIL)**
- **QR Code Generation**
- **Data Processing**
- **Image Processing**

## Results

The system was successfully used to generate **90 personalized QR-enabled event tickets** for an event.

The generated tickets contain unique QR codes that direct users to a verification interface where ticket validity and scan status can be checked.

## Project Context

Developed as part of the **Programming for Scientific Computing (PSC)** course at **Institute of Technology, Nirma University**.
